# 📚 Учебный Python Project

Консольный учебный проект на Python с модульной структурой.

Проект демонстрирует:
- работу с текстом;
- работу со списками и словарями;
- сохранение данных;
- работу с TXT / CSV / JSON файлами;
- организацию проекта по модулям;
- базовую работу с Git и GitHub.

---

# 🚀 Возможности

## 📄 Работа с текстом
- очистка текста;
- подсчёт слов;
- поиск слова в тексте.

## 👩‍🎓 Работа со студентами
- поиск по имени;
- фильтрация по параметрам;
- подсчёт элементов.

## 📁 Работа с файлами
- сохранение и чтение TXT;
- работа с CSV;
- работа с JSON.
