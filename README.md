# Math Optimization Project

## 📌 Описание проекта

Данный проект реализует модель оптимизации функции потерь с использованием алгоритма градиентного спуска.

Проект показывает, как функция может приближаться к своему минимуму с помощью итеративного обновления параметра.

---

## 🎯 Цель проекта

- реализовать функцию потерь
- вычислить её производную
- применить градиентный спуск
- визуализировать процесс оптимизации
- структурировать проект по модулям

---

## 📊 Математическая модель

Функция потерь:

\[
L(x) = (x - 4)^2 + 1
\]

Производная:

\[
L'(x) = 2(x - 4)
\]

Минимум функции:

- x = 4  
- L(x) = 1  

---

## ⚙️ Алгоритм

1. Задаётся начальное значение x
2. Вычисляется производная
3. Обновляется x по формуле:

x = x - learning_rate * gradient

4. Повторяется несколько шагов
5. Получаем приближение к минимуму
